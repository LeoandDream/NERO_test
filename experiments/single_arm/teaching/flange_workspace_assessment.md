20 秒会话的最后一条有效记录为 J4 `−0.982900 rad`，停止并停稳后只读反馈约为 `−1.0233 rad`（约 `−58.63°`）。因此，**当时的姿态在用户指南的标称范围内，但超出 SDK 预设范围**；这不是仅由脚本的 0.01 rad 余量造成的。当时机械臂反馈 `NORMAL`、错误码 `0x0000`，但会话元数据仍为 `return_completed=false`。通过 SDK 查询 J4 控制器限位时未收到有效返回，不能据此推断控制器内部设置。

以上 `−1.0233 rad` 是 **2026-09-23 23:34 手动恢复尝试之前** 的读数。该次尝试进入拖动后发生大幅姿态变化，已中断且未自动回位；当次恢复尝试结束后的稳定姿态 J4 约为 `−0.0377 rad`，详情见[过程记录](report.md#后续-20-秒试验)。原 20 秒记录缺少停稳轨迹，不能用于自动倒序回位。

## 运动学与保护范围

目前的 [示教控制脚本](teach_session.py)用七个关节角记录轨迹；示教结束后从实时七轴反馈重新规划少量 `move_j` 目标回 S1，不倒放 CSV。回到同一法兰位姿不能保证七个关节也回到 S1，因此位置复位验收七轴反馈。SDK 提供的 `fk()` 已在本机静止姿态与法兰反馈核对，可用于计算各关节轨迹采样点的法兰位置。

[默认示教配置](../config/nero_teach.json)支持 `flange_workspace_m`，格式为 `{"x": [下限, 上限], "y": [...], "z": [...]}`，单位米。配置生效时，脚本在起点和示教记录上用 FK 检查法兰中心；新回位规划另对每段关节插值与关节盒的法兰范围做抽查。**当前值为 `null`，通用法兰范围保护尚未启用**，因为现场安全边界还未确定；新回位仅有本现场的基座 X 下限。关节角限位仍需保留：即使法兰中心处于允许区域，关节或其他连杆也可能到达自身边界或碰到障碍。不能直接把上表的观测极值当作安全边界。

在现场确认机械状态并使 J4 回到已确认可控制的范围后，可通过 CAN 拖动示教配合 [连续记录脚本](../pose_recording/record_poses.py)重新采样边界点，再运行：

```bash
python -m experiments.single_arm.pose_recording.analyze_workspace experiments/single_arm/pose_recording/data/recordings/新记录.csv --output experiments/single_arm/pose_recording/data/measurements/新观测范围.json
```

记录时需标明哪些点是现场确认的安全边界，以及法兰周围工具、台面或其他障碍物的位置。正向回放或新的末端运动控制应在边界通过现场复核后再启用。
