# 单臂实验接口实施与验收门槛

## 边界

- `lab.api` 在导入时不创建机器人或打开 CAN。所有设备连接经注入的工厂建立；离线记录发现、立方体拟合及起点列表无需设备。
- 新示教快速回放明确采用现有逐点 `move_j` 语义。固定 20 秒记录的定时连续回放仍由 `continuous_replay` 实现；新记录不会静默改用它。
- 新示教的元数据记录 CSV 与配置 SHA-256、固件档位和关节起点。只把 `time_limit`、已补录停稳、已完成回位且哈希匹配的记录列为可快速回放。
- 命名起点仅有 S1 和显式选择的 C2。C2 路线来自已独立验收的源前缀；对其它当前姿态拒绝自动规划。不会把 C2 写入公共 S1。
- 立方体标定每面至少三个不共线法兰采样；六面齐全、面内残差、法向正交、对面平行和三边等长才标几何有效。输出没有运动许可含义。

## 实机前置与停止

同一运行只有一个运动命令源。预检和执行都重新读取新鲜 CAN 状态、七轴使能、稳定关节与法兰反馈；规划文件绑定配置、原始数据和实时起点。不同起点、未封存记录、异常状态、记录哈希变化、桌面/支撑/线缆条件变化均拒绝继续。实机运行前由现场确认监护、底座、工具、安装方向、扫过区域、支撑与停止方式。异常后保留最后目标和实测反馈，不推定自动回起点。

## 量化验收

- 快速回放：来源哈希匹配、所有计划小步按序执行、七轴反馈和报告齐全、终点返回本轮起点最大单关节误差 ≤0.005 rad，最后状态 `NORMAL`。
- 初始化：精确命名起点，完整路径目标/CAN 与反馈报告，最终目标误差 ≤0.005 rad 且稳定、七轴使能；不接受未知姿态直跳。
- 几何立方体：六面各≥3 个非共线样本，面残差≤0.005 m、对面法向平行偏差≤8°、相邻法向正交偏差≤8°、三边长度相对均值偏差≤5%；几何结果不等于可安全穿越的体积。
- 离线：有效和损坏记录、latest 选择、导入无设备副作用、立方体六面/缺面/长方体、命名起点与配置失效、旧 CLI 的离线兼容测试。
