# S1 法兰沿基座 X 负方向运动

使用[位置逆解脚本](cartesian_x_session.py)从机械臂**实时** S1 姿态生成轨迹。法兰中心沿基座 X 减小指定距离，Y/Z 近似保持，姿态允许变化。脚本使用 SDK 正运动学和七关节数值雅可比求解；逆解对 J4 施加权重，避免靠近此前触发的 J4 边界。返回时沿外行程关节路线倒序执行，目标是**本次实际起点**。

2026-09-24 的 10 cm 往返在每个小步交界处出现顿挫。旧算法每 5 mm 求解位置目标，并细分为最多 0.05 rad 的关节指令，去回程合计 52 次到位等待。新版每约 10 mm 求解一次，关节指令跨度上限为 0.10 rad，仍对指令之间每约 0.01 rad 做 FK、限位和法兰通道检查。此修改只减少逐点停启次数，**尚未实机验证能否消除顿挫**；下一次建议先只读规划 2 cm 短行程。

在工作区根目录执行只读规划：

```bash
conda activate nero-py310
python -m experiments.single_arm.cartesian_x.cartesian_x_session --distance-m 0.02
```

规划保存在 `experiments/single_arm/cartesian_x/data/plans/nero_cartesian_x_*.json`。若机械臂已离开 S1，脚本会拒绝规划。规划前检查状态、驱动反馈、停稳程度，以及 SDK 正运动学与 CAN 法兰反馈的一致性。规划时对每段关节路径约每 0.01 rad 检查一次法兰中心，要求 X 单调减小、Y/Z 偏差不超过 3 mm，并检查七关节 SDK 限位及零位排除范围。默认 `flange_workspace_m` 仍为 `null`，这里的计算范围不是现场碰撞边界。

旧版 10 cm [历史执行记录](data/plans/nero_cartesian_x_20260924T102125Z.json)从 S1 附近出发，外行程 26 小步，目标 X 约 `0.2820 m`，J4 距脚本边界最近约 `0.1348 rad`。该规划已执行且属于旧版算法，不能被新版脚本复用。**整个机械臂的连杆都会改变姿态**；法兰走直线不代表连杆扫过的空间没有障碍。

执行前可复核规划：

```bash
python -m experiments.single_arm.cartesian_x.cartesian_x_session --plan experiments/single_arm/cartesian_x/data/plans/新规划文件.json
```

复核会重新计算逆解，拒绝改动、重复或已尝试执行的规划；若当前位置与记录的起点相差超过 `0.005 rad`，需重新生成。现场确认底座固定、安装方向和零点正确，**从 S1 到目标再返回时整条连杆扫过的范围**无人员、台面或其他障碍，并有人现场监护后，执行：

```bash
python -m experiments.single_arm.cartesian_x.cartesian_x_session --plan experiments/single_arm/cartesian_x/data/plans/新规划文件.json --run
```

脚本倒计时 5 秒，以 5% 速度逐步发送关节指令；每步检查状态、七个驱动、关节路径、实时法兰通道和目标误差。外行程终点必须在法兰目标 5 mm 内，返回后每关节须在本次实际起点 0.005 rad 内。`Ctrl+C` 中止；已发送运动指令后遇到路径或状态异常，脚本会调用电子急停并记录失败结果。**中止或故障时不保证自动返回起点**，应先核对机械臂状态和当前位置，再决定后续动作。规划只能执行一次。

## 2026-09-24 旧版实机往返

现场确认底座固定、整条连杆活动范围清空且有人监护后，使用上述规划以 5% 速度完成 26 步外行程和 26 步原路返回；每步关节和法兰反馈检查均通过。[规划及执行记录](data/plans/nero_cartesian_x_20260924T095015Z.json)标记 `executed=true`，当次返回时最大单关节误差约 `0.000209 rad`。

执行后独立只读核对：机械臂 `CAN_CTRL`、`NORMAL`、示教禁用、错误码 `0x0000`，七个驱动检查通过；与本次实际起点的最大单关节误差约 `0.000070 rad`，法兰反馈距规划起点约 `0.000025 m`。这只验证了这一次路径。下次执行须从实时姿态重新生成规划并确认现场范围；已执行的规划不能复用。
